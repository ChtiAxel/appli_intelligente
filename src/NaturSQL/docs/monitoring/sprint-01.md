SPRINT 01 :

US-11 : En tant qu'utilisateur, je veux accéder à une page d'accueil (Home) ergonomique servant de point d'entrée au chat.

US-12 : En tant qu'utilisateur, je veux voir s'afficher un panneau latéral (sidebar) statique listant l'historique de mes anciennes conversations fictives.

US-13 : En tant qu'utilisateur, je veux pouvoir cliquer sur une ancienne conversation pour charger son contenu visuel à l'écran.

US-14 : En tant qu'utilisateur, je veux pouvoir supprimer une conversation de mon historique pour faire du tri dans l'interface.

US-15 : En tant qu'utilisateur, je veux pouvoir créer une nouvelle discussion en un clic pour réinitialiser le fil de discussion.

US-16 : En tant qu'utilisateur, je veux disposer d'une zone de saisie de texte (input de chat) et d'un bouton d'envoi ergonomique.

US-17 : En tant qu'utilisateur, je veux voir mes messages s'afficher instantanément dans une interface de type chat conversationnel.

US-18 : En tant qu'utilisateur, je veux que l'interface web globale soit responsive et fluide sur tous les écrans.
