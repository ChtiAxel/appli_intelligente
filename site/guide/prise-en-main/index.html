    Guide de Prise en Main

    Ce guide vous accompagne pas à pas dans vos premiers pas sur NaturSQL. Aucun prérequis technique n'est nécessaire.

    1. Accéder à l'application

    NaturSQL est une application web accessible depuis n'importe quel ordinateur connecté au réseau de l'établissement ou à votre environnement local.

    1. Ouvrez votre navigateur internet favori (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
    2. Entrez l'adresse de l'application fournie par votre administrateur (ex. : http://localhost:7860 ou l'adresse du serveur distant).
    3. L'écran d'accueil s'affiche.

    2. Créer son compte (Sign Up)

    Si vous utilisez l'application pour la première fois, vous devez créer un compte utilisateur :

    1. Sur l'écran d'accueil, cliquez sur le lien « Créer un compte » situé sous le formulaire.
    2. Complétez les champs demandés :
    3. Prénom : Votre prénom (ex. : Jean).
    4. Nom : Votre nom de famille (ex. : Dupont).
    5. Mot de passe : Choisissez un mot de passe robuste (au minimum 8 caractères, comprenant une majuscule, un chiffre et un caractère spécial).
    6. Confirmer le mot de passe : Retapez exactement le même mot de passe.
    7. Cliquez sur le bouton bleu « S'inscrire ».
    8. Un message vert de confirmation s'affiche. Vous pouvez maintenant vous connecter !

    3. Se connecter (Sign In)

    Une fois votre compte créé, connectez-vous pour accéder aux fonctionnalités de recherche :

    1. Sur le formulaire de connexion (Sign In) :
    2. Saisissez votre Prénom (ex. : Jean).
    3. Saisissez votre Nom (ex. : Dupont).
    4. Saisissez votre Mot de passe.
    5. Cliquez sur le bouton « Se connecter ».
    6. Vous êtes immédiatement redirigé vers votre tableau de bord personnel.

    4. Consulter et modifier son profil

    Dès votre connexion, votre carte de profil s'affiche :

    • Visualisation : Votre nom complet ainsi que votre avatar s'affichent.
    • Modifier vos informations :
    • Cliquez sur le bouton « Modifier le profil ».
    • Deux champs apparaissent pour ajuster votre prénom et votre nom si nécessaire.
    • Cliquez sur le bouton vert « Enregistrer » pour sauvegarder les modifications.

    5. Se déconnecter

    Pour protéger la confidentialité de vos consultations, déconnectez-vous en fin de session : * Cliquez simplement sur le bouton rouge « Déconnexion » présent sur la page de votre profil. * Vous serez automatiquement redirigé vers l'écran de connexion initial.
