# Guide de Prise en Main

Ce guide vous accompagne pas à pas dans vos premiers pas sur **NaturSQL**. Aucun prérequis technique n'est nécessaire.

---

## 1. Accéder à l'application

NaturSQL est une application web accessible depuis n'importe quel ordinateur connecté au réseau de l'établissement ou à votre environnement local.

1. Ouvrez votre navigateur internet favori (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
2. Entrez l'adresse de l'application fournie par votre administrateur (ex. : `http://localhost:7860`).
3. L'écran d'accueil s'affiche.

---

## 2. Créer son compte (Sign Up)

Si vous utilisez l'application pour la première fois, vous devez créer un compte utilisateur :

1. Sur l'écran d'accueil, cliquez sur le lien **« Créer un compte »** situé sous le formulaire.
2. Complétez les champs demandés :
   - **Prénom** : Votre prénom (ex. : *Jean*).
   - **Nom** : Votre nom de famille (ex. : *Dupont*).
   - **Mot de passe** : Choisissez un mot de passe robuste (au minimum 8 caractères, comprenant une majuscule, un chiffre et un caractère spécial).
   - **Confirmer le mot de passe** : Retapez exactement le même mot de passe.
3. Cliquez sur le bouton bleu **« S'inscrire »**.
4. Un message de confirmation s'affiche. Vous pouvez maintenant vous connecter !

## 3. Se connecter (Sign In)

Une fois votre compte créé, connectez-vous pour accéder aux fonctionnalités de recherche :

1. Sur le formulaire de connexion (**Sign In**) :
   - Saisissez votre **Prénom** (ex. : *Jean*).
   - Saisissez votre **Nom** (ex. : *Dupont*).
   - Saisissez votre **Mot de passe**.
2. Cliquez sur le bouton **« Se connecter »**.
3. Vous êtes immédiatement redirigé vers l'interface de conversation.

## 4. Consulter et modifier son profil

Dès votre connexion, vous pouvez accéder à votre profil en haut à droite :

1. Cliquez sur **« Mon Profil »**.
2. **Modifier vos informations** :
   - Cliquez sur le bouton **« Modifier le profil »**.
   - Deux champs apparaissent pour ajuster votre prénom et votre nom.
   - Cliquez sur le bouton bleu **« Enregistrer »** pour sauvegarder les modifications.
3. Cliquez sur **« Retour aux conversations »** pour revenir à l'assistant.

## 5. Utiliser le Chatbot et l'Historique (Sidebar)

L'interface de conversation est divisée en deux parties : **la Sidebar (à gauche)** et **le Chatbot (à droite)**.

### Le Chatbot
1. Dans le champ de texte en bas à droite, saisissez votre question. 
2. Validez en cliquant sur le bouton d'envoi.
3. L'assistant vous répondra avec un bloc de code SQL (la requête générée en transparence) et la réponse en texte clair.

### La Sidebar (Historique)
1. **Nouvelle discussion :** Cliquez sur le bouton **« + »** pour recommencer à zéro.
2. **Rechercher :** Utilisez la barre "Search" pour filtrer et retrouver une ancienne conversation.
3. **Consulter l'historique :** Cliquez sur une des discussions listées pour la recharger.

## 6. Se déconnecter

Pour protéger la confidentialité de vos consultations, déconnectez-vous en fin de session :
* Depuis l'interface, cliquez sur **« Mon Profil »** puis sur le bouton rouge **« Déconnexion »**.
